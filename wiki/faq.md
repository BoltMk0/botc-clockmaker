# Frequently asked questions

## Getting in

**What's the password?**
There's one shared password for the whole site. Ask whoever set up the server. If it's been forgotten, they can
reset it.

**Other devices can't open Clockmaker.**
Make sure they're on the same network as the server, and use the same web address that works on your other
devices.

**Can players open the town square on their phones?**
No, it needs the password. Show them the script QR code on the town square instead: the script viewer doesn't.

## Sound

**There's no bell when the timer runs out.**
- A new install has no sounds: see [Add a bell sound](quickstart.md#6-add-a-bell-sound).
- Click or tap the town square page once after opening it. Browsers block sound until you do.
- Check **Audio Engine** is ticked in the town square's ☰ menu on the screen that should play sound.

**The bell rings twice or echoes.**
More than one screen is playing sound. Untick **Audio Engine** in the ☰ menu on all but one of them.

## The grimoire

**There are no scripts to choose.**
Download them first: see [Get the characters and scripts](quickstart.md#get-the-characters-and-scripts-once).

**"Draw tokens" is greyed out.**
The bag must hold exactly one token per player. Move any extra tokens to **On the grim**.

**A token won't move.**
The tokens are locked. Press the lock in the grimoire's sidebar to unlock them.

**The players' names don't show on the town square.**
Names come from the grimoire and appear in the **Clocktower (3D)** display mode. Every player needs a name on their
token.

## The display

**The 3D clocktower is slow.**
Choose a simpler **Display Mode** in the town square's ☰ menu. It only changes that one screen.

**The clock is too big or too small.**
Untick **Display Size → Auto** in the ☰ menu and use the slider.
