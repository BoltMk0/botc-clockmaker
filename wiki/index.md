# Welcome to Clockmaker

Clockmaker helps you run in-person games of *Blood on the Clocktower*. It puts a big day/night clock on a screen in
the town square, turns your phone into a remote for it, and can replace your physical grimoire with one on a tablet.
Every screen stays in sync: start the timer on your phone and the clock on the TV starts counting down.

These pages are for storytellers who want to get playing. If you're installing or looking after the server itself,
see the [developer documentation](/help/developer).

## Where to start

- **New here?** Follow the [Quickstart: your first game](./01_quickstart/index.md). It takes you from an empty install to a
  running game in about ten minutes.
- **Looking for a button?** [Finding your way around](./finding-your-way-around.md) is a map of every page and what's on it.
- **Something not working?** Try the [frequently asked questions](./04_faq.md).

## What you'll need

- A **screen everyone can see** — a TV, monitor or projector connected to anything with a web browser (a laptop,
  mini-PC, smart TV or tablet). This shows the town square clock.
- A **phone** for you, the storyteller, to control the clock.
- Optionally, a **tablet** for the virtual grimoire.
- The Clockmaker **web address** and **password**, from whoever set up the server.

All devices just need a web browser and to be on the same network as the server. There's nothing to install, though
you can add Clockmaker to your home screen to use it like an app.

## The home screen

| Button | What it's for |
| --- | --- |
| **Play** | Your games: create them, and open each one's town square, remote and grimoire. |
| **Rules** | A slideshow of the rules, for players. Only shown once someone has uploaded rules slides. |
| **Settings** | Everything shared between games: characters, scripts, timers, sounds, music and more. |
| **Help** | These pages. |
