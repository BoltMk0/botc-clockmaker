# Settings → Timer Options

[← Settings overview](README.md) · [Documentation home](../README.md)

The countdown buttons offered on the [clock remote](../clock-remote.md#timer-options), shared by every game.

Each row is one option:

| Column | What it means |
| --- | --- |
| **Label** | The name on the button, e.g. "5 Minutes" or "Day 1". |
| **Duration** → **Minutes** / **Seconds** | How long the day's countdown is. |
| **Reminder At** | Tick to ring the **reminder bell** (and show *"The end of the day is approaching…"* on the town square) with this many **seconds** left. Ticking it starts at 60 s. Untick for no reminder. |
| 🗑 | Delete the option. |

**Add Option** adds a row (10 minutes, no reminder). Options appear on the remote in the order listed.

Changes aren't saved until you press **Save changes** (it lights up when there's something to save).

The defaults are: *Example* (5 s, reminder at 4 s — handy for testing your bells), *1 Minute* (no reminder),
and *3*, *5*, *8* and *10 Minutes* (each with a reminder at 30 s).

Tip: rather than strictly following the clock, many storytellers keep a few options of decreasing length (for
example 8, 5 and 3 minutes) to shorten the days as the player count drops.
