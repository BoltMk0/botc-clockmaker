# Settings → QR Codes

[← Settings overview](README.md) · [Documentation home](../README.md)

QR codes to show on the town square, shared by every game — for example a link to the
[feedback form](../player-pages.md#the-feedback-form), your group's website or chat, or a ticketing page.

Each entry has:

| Field | Notes |
| --- | --- |
| **Title** | Shown with the code. |
| **URL** | Where the code leads. A full address (`https://…`), or a path on this site such as `/feedback`, which is turned into a full link to this server. |
| **Position** | Where on the screen it sits: top left, top, top right, left, right, bottom left, bottom or bottom right. Codes sharing a position are stacked together. |

**+ Add** adds an entry, **✕** deletes one, and **Save** saves the list.

Custom QR codes are only shown on town squares where **Show Custom QR** is ticked in the
[☰ menu](../town-square.md#the--menu) (it's off by default). The same menu sets the QR size, and the separate
**Script QR**, which links players to the current game's script.
