# Settings → Grim Messages

[← Settings overview](README.md) · [Documentation home](../README.md)

Saved messages to show players, listed in the grimoire's
[communications menu](../grimoire.md#communications-showing-things-to-players) in every game. Use them for anything
you find yourself showing often that isn't built in — for example *"You are drunk"*, *"You have been poisoned"*, or
character-specific info like *"These characters are in play"*.

## Building a message

A message is a stack of **fields**, shown top to bottom in large type:

- a **Text** field — a line of text. The first field of a message is shown as its title, and is also the
  message's button label in the grimoire (with "…" if there's more to it);
- a **Character** field — a row of character tokens.

For each message:

- **+ Add field**, then choose **Text** or **Character** (or **Cancel**).
- For a character field, **+** adds a token slot. Tap a slot to choose a character for it, or **Empty** to leave
  it as a **blank** (shown as "?").
- **✕** removes a field; **Delete message** removes the whole message.

**+ Add Message** starts a new one. Press **Save changes** when you're done.

## Blank character slots

A blank slot is filled in when the message is used. For example, a message *"This character is in play"* with one
blank token: in the grimoire, picking it asks *"Which character fills the blank?"*, and shows the message with the
character you choose. A message with several blanks asks for each in turn.

For one-off messages during a game, use **Custom message…** in the grimoire's communications menu instead — it
builds a message the same way without saving it.
