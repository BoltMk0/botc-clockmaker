Lightscapes

Zigbee lighting for Clockmaker

Clockmaker

The Clockmaker to follow, and the game. The API token is in Clockmaker's Settings → API Token.

Phases

What the lights are set to in each phase of the game.

Day spectrum

Colours the lights fade through as the day's countdown runs, like the town square's sky: from dawn at the start to the night sky as it runs out.

Bells

Lights to flash when a bell rings, held for a moment before going back to the phase's.

Buttons

Zigbee buttons as a clock remote. Pair them in Zigbee2MQTT first.
